⚙️ Software Environment Prerequisites & Setup Instructions ▾

Ensure your personal workstation or lab PC has the following standard software installed before attending sessions:

  • Web Development Track: Modern Evergreen Browser (Chrome 120+, Firefox 122+, or Edge), Visual Studio Code with Live Server extension.
  • Cloud & DevOps Track: Docker Desktop / Engine v24+, Git CLI 2.40+, and Bash/Zsh terminal shell.
  • Embedded IoT Track: Arduino IDE 2.3+ or VS Code with PlatformIO, CP210x USB to UART Bridge VCP Drivers.
  • AI & Data Science: Python 3.11+, JupyterLab, NumPy, Pandas, and PyTorch (CPU or CUDA enabled).
📋 Hardware Safety & Lab Equipment Handling Protocol ▾

All hardware kit recipients must adhere to standard university electronics handling protocols:

  • Always disconnect USB power before modifying circuit connections on the solderless breadboard.
  • Do not exceed 3.3V input on ESP32 GPIO pins to prevent sensor or controller gate burnout.
  • Hardware kits are issued under student university registration numbers and must be checked back in following the final showcase.
